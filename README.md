# Happy Teacher's Day, Dr. Mohammad Faisal Noor | LMTSM

A dedicated tribute website celebrating **Dr. Mohammad Faisal Noor** (Assistant Professor of Operations & Quantitative Techniques, LM Thapar School of Management) on Teacher's Day, featuring heartfelt video messages from students of **Quantitative Techniques for Management (QTM)**.

## Features
- **Hero Profile**: High-resolution portrait, academic credentials (Ph.D., NIT Jamshedpur), and links to LMTSM faculty directory.
- **5 Student Video Wishes**:
  1. **Pallavi Chaudhary** (Section D) - 0:55
  2. **Balreet Sharma** (Section C) - 0:37
  3. **Navjot Kaur** (Section D) - 0:32
  4. **Gunvir Singh** (Section D) - 0:27
  5. **Aneesha** (Section D) - 0:18
- **Section Filter Pills**: Filter wishes by *All (5)*, *Section D (4)*, and *Section C (1)*.
- **Fullscreen Reel Player**: Direct fullscreen modal playback with next/prev buttons, counter badges, keyboard controls, and auto-advance.
- **HTTP 206 Video Streaming**: Built-in PowerShell HTTP server with partial content byte-range streaming for instantaneous video seeking.

## How to Run Locally
Double-click `run-tribute-site.bat` or run:
```powershell
powershell -ExecutionPolicy Bypass -File .\tribute-server.ps1 -Port 3002
```
Open your browser at `http://localhost:3002/`.
